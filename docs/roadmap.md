# Roadmap

## TASK 001 — фундамент (текущий этап)

- Go-модуль, структура пакетов, Clean Architecture без избыточности.
- Доменные модели и строгие идентификаторы.
- Машина состояний `VideoJob` с проверкой переходов.
- Порты внешних сервисов и контракт ежедневного workflow.
- Планировщик 09:00 MSK и 24-часовое окно.
- Бюджеты и журнал расходов, реестр идемпотентности.
- Unit-тесты, CI, документация, ADR.

## TASK 002 — YouTube API Integration Test

- OAuth 2.0 с refresh token, безопасное хранение секретов.
- Загрузка тестового видео, получение YouTube ID.
- `youtube.VideoPublisher` как реальная реализация порта.
- Контрактные тесты на записанных ответах.

## TASK 003 — сбор и отбор новостей

- RSS/API-источники, дедупликация, окно 24 часа.
- LLM-ранжирование и факт-чек с цитатами.
- `editor.SelectStories` на реальных данных.

## TASK 004 — сценарий, озвучка, визуал

- Генерация русского сценария с таймингом.
- TTS-провайдер, нормализация громкости.
- Генерация визуальных клипов, лицензирование музыки.

## TASK 005 — рендер и валидация

- FFmpeg-пайплайн 1080×1920, 15–30 секунд.
- Субтитры, безопасные зоны, проверка аудиодорожки.
- `VideoValidator` как обязательный шлюз перед загрузкой.

## TASK 006 — Temporal и PostgreSQL

- Workflow `DailyRunWorkflow`, activity на каждый порт.
- Схема БД, репозитории, уникальные индексы идемпотентности.
- Восстановление после падений, ретраи с backoff.

## TASK 007 — эксплуатация

- MinIO, Docker Compose, healthcheck-и.
- Метрики, алерты, отчёты в Telegram.
- Ограничения расходов на уровне прогона и дня.
