# configs

Каталог для файлов конфигурации окружений (`local`, `staging`, `production`).

На этапе TASK 001 конфигурация не загружается: приложение не имеет внешних
зависимостей, а все значения по умолчанию заданы в домене (`domain.MoscowSchedule`,
`domain.MaxStoriesPerRun`, `domain.NewsWindow`).

Когда появится загрузчик конфигурации, файлы здесь будут содержать только
нечувствительные значения; секреты останутся в переменных окружения.
